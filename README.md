# Study Planner

A Django web app for organizing study topics, planning around exam dates, and tracking study progress.

**Live app:** [Open Study Planner](https://study-planner-z22t.onrender.com/)

## Features

- Create an account and manage your own study topics
- Add subjects, topics, exam dates, priorities, notes, and completion status
- Search and filter topics by status, priority, tag, or exam-date range
- Organize topics with color-coded tags
- Record study sessions and review study time
- Create recurring topic templates and generate topics from them
- Configure preferences for upcoming-exam reminders
- Switch between light and dark themes and use keyboard shortcuts

Email delivery requires an email service to be configured.

## Built with

- Python and Django
- HTML, CSS, and JavaScript
- Render for deployment
